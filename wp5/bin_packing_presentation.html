Solving 1D Bin Packing with AlphaZero

Problem

  • Pack n items with sizes si∈(0,1]s_i \in (0,1]si​∈(0,1] into unit-capacity bins, minimising bin count
  • NP-hard; optimal solution known at instance-generation time (used as benchmark)
  • Instance generation: draw bin types (each type = [0,1][0,1][0,1] cut into 1–4 pieces ≥smin\ge s_\text{min}≥smin​), replicate each type 1–16 times, flatten and sort descending — optimal bin count equals total bin instances created
  • Items pre-sorted descending; agent assigns one item per step

Environment

  • State: flat vector of length 2n2n2n
    • obs0:n\text{obs}_{0:n}obs0:n​ — remaining capacities of open bins (action-index order, zero-padded)
    • obsn:2n\text{obs}_{n:2n}obsn:2n​ — unassigned item sizes (descending, zero-padded)
  • Action: bin index a∈{0,…,n−1}a \in \{0,\dots,n-1\}a∈{0,…,n−1}; legal if cap[a]≥scurrent\text{cap}[a] \ge s_{\text{current}}cap[a]≥scurrent​, or aaa is the next-unused slot (opens a new bin)
  • Reward: rt=−1[new bin opened]r_t = -\mathbf{1}[\text{new bin opened}]rt​=−1[new bin opened]; total return =−(bins used)= -(\text{bins used})=−(bins used)

We use a transformer to handle variable-length inputs — the same network weights apply to any number of items nnn, so instances of arbitrary size are supported without retraining or architectural changes.

Runtime O(n⁴)

Three multiplicative factors:

  • Transformer forward pass: sequence length S=O(n)S = O(n)S=O(n), attention matrix O(n2)O(n^2)O(n2) — one network call costs O(n2)O(n^2)O(n2)
  • Each simulation calls the network once; we run K=O(n)K = O(n)K=O(n) simulations per step (proportional to action-space size)
  • An episode has exactly nnn steps
